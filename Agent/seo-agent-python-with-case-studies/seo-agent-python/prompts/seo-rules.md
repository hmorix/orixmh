# SEO Rules

> This document defines the SEO standards for all HMorix content. Every blog post, landing page, press release, product page, and documentation page must follow these rules unless explicitly instructed otherwise.

---

# SEO Objectives

Every page should aim to:

- Rank for relevant search queries.
- Provide genuine value to readers.
- Satisfy search intent.
- Demonstrate expertise and trustworthiness.
- Encourage user engagement.
- Improve organic traffic.
- Generate qualified leads.

The AI must always prioritize helpful content over keyword stuffing.

---

# Keyword Rules

## Primary Keyword

Must appear in:

- SEO Title
- H1
- URL Slug
- First Paragraph
- Meta Description
- One H2 heading
- Conclusion

Target density:

- Approximately 1–2%
- Never force keywords unnaturally.

---

## Secondary Keywords

Include naturally throughout the article.

Use:

- Synonyms
- Related searches
- Long-tail keywords
- Semantic keywords

Avoid repeating identical phrases excessively.

---

# SEO Title

Requirements:

- Under 60 characters
- Primary keyword near the beginning
- Human-friendly
- Clear
- Specific

Good Example

AI Website Development Guide for Small Businesses

Avoid

The Ultimate Best Amazing AI Website Development Guide Ever

---

# Meta Description

Requirements:

- Under 160 characters
- Includes primary keyword
- Summarizes the page accurately
- Ends with a reason to continue reading
- No clickbait

---

# URL Slug

Rules:

- Lowercase only
- Hyphen-separated
- Short
- Descriptive
- Primary keyword included
- Remove stop words where practical

Good Example

ai-business-automation

Avoid

the-best-guide-to-ai-business-automation-for-everyone

---

# Heading Structure

Use only one H1.

Recommended structure:

- H1
- Introduction
- H2
- H2
- H3
- H3
- H2
- FAQ
- Conclusion

Never skip heading hierarchy.

---

# Content Length

Minimum recommendations:

News:
600–900 words

Blog:
1200–2500 words

Ultimate Guide:
2500–5000 words

Documentation:
As needed

Landing Page:
800–1500 words

---

# Table of Contents

Required for articles over 1500 words.

Should appear immediately after the introduction.

---

# Internal Linking

Every article should include at least 3–8 relevant internal links.

Examples:

- /
- /about
- /services
- /products
- /contact
- /blogs
- /pricing

When possible:

- Link related blogs.
- Link related services.
- Link related products.

---

# External Links

Every article should include 2–5 authoritative sources when factual claims require support.

Preferred sources include:

- Google Search Central
- Google Developers
- Google AI
- Microsoft Learn
- Mozilla Developer Network (MDN)
- W3C
- WHATWG
- OWASP
- OpenAI
- Anthropic
- NVIDIA
- Hugging Face
- Cloudflare
- Vercel
- Node.js
- React
- TypeScript
- Supabase
- PostgreSQL
- MariaDB
- MongoDB
- Python
- Linux Foundation
- GitHub Docs

Never cite low-quality or spam websites.

---

# Image SEO

Every suggested image must include:

- Descriptive filename
- Alt text
- Caption (optional)

Example

Filename:

ai-business-dashboard.webp

Alt:

Dashboard showing AI-powered business automation analytics.

---

# Schema Markup

Every blog must generate valid Schema.org JSON-LD.

Preferred types:

- BlogPosting
- Article

Include:

- headline
- description
- author
- publisher
- datePublished
- dateModified
- image
- keywords
- mainEntityOfPage

---

# FAQ Section

Include 3–5 People Also Ask style questions.

Answers:

- 40–80 words
- Accurate
- Helpful
- Natural language

---

# Readability

Target:

- Grade 7–9 reading level
- Short paragraphs
- Active voice
- Bullet lists where useful
- Clear examples

---

# EEAT Guidelines

Every article should demonstrate:

- Experience
- Expertise
- Authoritativeness
- Trustworthiness

Never invent:

- Statistics
- Customer stories
- Certifications
- Research findings

---

# Freshness

Review important articles every 6–12 months.

Update:

- Statistics
- Product information
- Pricing
- Screenshots
- Links
- References

---

# Backlink Strategy

Prefer earning backlinks naturally through high-quality content.

Target backlink sources:

- Business directories
- Startup directories
- GitHub
- Product Hunt
- Dev.to
- Hashnode
- Medium
- LinkedIn Articles
- Google Business Profile
- Crunchbase (if applicable)
- Local business listings
- Industry blogs
- University resources
- Government references (when appropriate)

Never:

- Buy backlinks.
- Participate in link farms.
- Use private blog networks (PBNs).
- Use automated backlink software.
- Exchange spam links.

---

# Technical SEO Checklist

Every page should include:

- Unique title
- Unique meta description
- Canonical URL
- robots meta tag
- Open Graph tags
- Twitter/X Card tags
- Structured Data
- XML Sitemap inclusion
- robots.txt compatibility
- Mobile-friendly layout
- HTTPS
- Fast loading
- Optimized Core Web Vitals
- Lazy-loaded images
- Compressed images (WebP/AVIF preferred)
