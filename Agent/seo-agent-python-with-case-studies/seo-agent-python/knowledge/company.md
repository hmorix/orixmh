HMorix is a unified enterprise technology and SaaS software corporation that develops next-generation AI platforms, complete multi-portal enterprise software, and business automation infrastructure. Founded by Harsh Sharma, HMorix bridges modern Silicon Valley-grade cloud engineering with accessible, practical digital transformation for enterprises, growing SMBs, and regional industries across India and global markets.

## Core Engineering & Architectural Principles

1. **AI-First & Autonomous:** Automated repetitive workflows (resume parsing, invoice tax calculations, SEO content generation, customer support triage) using NVIDIA NIM enterprise models.
2. **Zero-Trust Security & Enterprise Hardening:**
   - Native Google Two-Factor Authentication (RFC 6238 TOTP) with encrypted emergency recovery keys.
   - Active Session & Device Management with real-time IP, OS, and browser tracking.
   - Dual-Database automated backup and disaster recovery verification (MongoDB Atlas + Supabase PostgreSQL).
   - Strict Content Security Policy (CSP), rate limiting, and RBAC permission guards.
3. **No-Mock-Data Integrity:** Every portal (HRM, CRM, Sales, Employee, Manager, Client, Admin) connects directly to live production collections.
4. **Offline Resilience & Mobile-First:** Full PWA service worker with IndexedDB background sync, built to function reliably on mobile networks across Tier 1, Tier 2, and Tier 3 regions.
5. **Practical Value Over Hype:** No empty marketing buzzwords; solutions are engineered for measurable operational efficiency, verifiable cost reduction, and quantitative ROI.
